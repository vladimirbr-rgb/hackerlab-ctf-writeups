# Network Configuration Analysis

> Учебное задание HackerLab CTF по анализу сетевых конфигураций и клиентских файлов.

## Goal

Цель задания — проанализировать предоставленные клиентские конфигурации, изучить сетевые параметры и определить данные, необходимые для успешного завершения задания на платформе HackerLab.

## Environment

Работа проводилась в изолированной лабораторной среде:

- **Host OS:** Windows
- **Host terminal:** Windows PowerShell
- **Guest OS:** Ubuntu virtual machine
- **Guest shell:** Bash
- **Input artifacts:** клиентские файлы конфигурации и скриншоты выполнения.

Ubuntu VM была настроена и использовалась с Windows PC через PowerShell. Все команды выполнялись только в рамках учебного задания.

## Investigation

В рамках анализа были изучены предоставленные артефакты:

- клиентские конфигурационные файлы;
- сетевые параметры и адресация;
- параметры VLAN;
- результаты команд, выполненных в Ubuntu;
- данные, подтверждающие успешное прохождение задания.

## Methodology

1. Была подготовлена Ubuntu virtual machine для работы с учебными материалами.
2. Через Windows PowerShell был настроен доступ к окружению виртуальной машины.
3. Были изучены клиентские конфигурационные файлы.
4. Были сопоставлены сетевые параметры, VLAN-настройки и результаты анализа.
5. Полученный результат был проверен и отправлен на платформу HackerLab.
